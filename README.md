# Biosyn Coaching App - Flutter

نسخة Flutter من تطبيق Biosyn Coaching App بنفس التصميم والألوان.

## المميزات

- ✅ نفس الألوان (Primary Blue: #0066A1, Primary Cyan: #00AEEF)
- ✅ نفس اللوجو (blue-logo.png)
- ✅ نفس التدرجات اللونية للأزرار
- ✅ جميع الشاشات الأساسية

## الشاشات المتوفرة

### شاشات عامة
- Splash Screen
- Welcome Screen
- Login Screen
- Profile Screen

### شاشات District Manager (DM)
- DM Planning Screen
- DM Dashboard Screen

### شاشات General Manager (GM)
- GM Dashboard Screen
- GM Reports Screen
- User Management Screen

## التشغيل

```bash
flutter pub get
flutter run
```

## الملاحظات

- بعض الوظائف مثل Coaching Form و Export تحتاج إلى تطوير إضافي
- البيانات محفوظة محلياً باستخدام SharedPreferences
- جميع الألوان والتدرجات مطابقة للمشروع الأصلي
